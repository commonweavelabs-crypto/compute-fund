# Compute Fund — Outreach Strategy & Activation Plan (OUT-101)
*2026-10-10 · Windows Hermes · for Gui · action doc, not philosophy*

## 0. The one-liner
**"The platform that pays open-source maintainers in compute."**
Every outreach touch says one of three things, in this order of strength:
1. **Proof** (receipts exist — screenshots of real governed compute)
2. **Offer** (LLM tokens for maintainers — concrete, free, immediate)
3. **Ask** (fund a question / copy a project / star the repo)

Never lead with #3. Lead with #1 or #2, always.

## 3. Channels, ranked (effort × yield for a solo founder)
**A. Comment-seeding (you already started — systematize)**
- Target videos about: modding rights, game ownership, AI agents in coding, open-source
  maintainer burnout. These audiences overlap our exact user.
- The comment formula that works: **value-first, platform-second, link-on-request only**
  (link-in-comment = spam flag on YT/IG; "hit me up / ask and I'll share" is the
  algorithm-safe move you already used — keep it).
- Cadence: 3 quality comments/week (quality > volume; comment graveyard looks worse
  than silence). Track video URL + video age + engagement in `outreach-log/`.
- Upgrade path: when a video author replies, offer a compute grant + receipts screen-share.

**B. Reddit modding communities (the highest-yield channel we haven't touched)**
- r/skyrimmods-class subs host thousands of maintainers. The universal-modder repo is
  a **pre-built credibility pass** — post as its author, not as a founder pitching.
- Playbook: one value post (results/how-to, no pitch, fund link in profile), then
  answer every comment for 48h. Subreddit self-promo rules checked per sub, always.
- This is THE maintainer funnel: modders with real users (skyrimmods/Nexus counts)
  accepting compute grants = our first receipts-class projects.

**C. GitHub surface (passive but compounding)**
- universal-modder README: add a short "this project is funded via Compute Fund —
  receipts public" line + profile link (no hard CTA; the trust IS the ad).
- GitHub Sponsors on the org: zero-fee patronage rail goes live the day there's
  somewhere to land (the site's receipts page is the landing).
- gstack/REA moment: agent-workflow eyes are on GitHub right now (135k/56k spikes) —
  our tierllama ORIGIN.md + receipts architecture is well-timed; a SHOW&TELL issue or
  discussion post in those ecosystems costs nothing and rides the wave.

**D. X receipts posts (build-in-public)**
- Post format that works: screenshot of a receipt (model, tokens, cost, governed
  question) + one line. Numbers > adjectives. 2-3/wk, recycled from the archive's
  findings (today's market context helps: "everyone's racing to agent workflows;
  we've been routing for months — receipts" energy).
- Never argue with skeptics; receipts answer every round.

**E. YouTube episodes (the slow-burn flagship)**
- Per the Kallaway premium-spectrum data (archive: energy = high-effort visual
  explainers), the Jev-killer + receipts-reality episodes go out as CHARTED visual
  explainers, not talking heads. 1 video/month quality bar until engagement proves
  more cadence.
- Each episode description carries the funnel: receipts page → fund page → guide.

**Ranked by effort×yield for us right now: B (Reddit) > A (systematic comments) >
C (GitHub surface) > D (X) > E (YT) — E's episode work continues in parallel on
calendar time, not sprint time.**

## 4. The offer (what we actually say)
**Maintainer pilot: "Keep your project maintained on us."**
- We cover LLM-token compute for an open-source maintainer's real workload (issue
  triage, changelogs, compat testing) for a pilot window — capped, receipts-shared.
- What it costs us: spare Ollama capacity + the second key's quota. What it buys:
  real receipts, real governed-spend screenshots, 2-3 named pilot creators.
- THE PILOT IS THE MVP'S FIRST PROOF. No pilot creator, no receipts story — so the
  first goal of outreach is **3 pilot maintainers**, not patron volume.
- Honesty wall: no personal data shared, no keys exposed, receipts show model/tokens/
  cost/question only, and pilot recipients' usernames appear ONLY with their OK.

  count, outcome). If a channel yields 0 responses in 14 days, change the message
  before changing the channel; change the channel at 30 days.

## 6. Measurement (the only 3 numbers that matter pre-launch)
1. **Pilot maintainers onboarded** (target: 3 by month end)
2. **Receipt-quality engagements** (replies/DMs asking for the platform, not likes)
3. **Email/follow captures** on the site (add a one-field "get receipts updates"
   input on the org/start page — honest, non-addictive, v1.5.1)

## 7. Anti-asks (what we deliberately do NOT do now)
- No paid ads (nothing to measure against yet).
- No link-spam in comments (algorithm + community death).
- No "investor" framing anywhere (investors: none badge exists for a reason).
- No promising returns/margins to patrons — patronage framing only (Howey wall).
- No hiring, no agency, no cross-posting spam — one platform, one community, one
  honest thread at a time.
